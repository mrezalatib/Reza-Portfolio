# Reza Latib — Portfolio website

A responsive, static portfolio built with HTML, CSS and a small amount of JavaScript. No build tools or dependencies are required.

## Preview locally
1. Download and unzip the project.
2. Open the `reez-portfolio` folder.
3. Double-click `index.html` to open it in your browser.

For a local development server, open Terminal in this folder and run:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## Personalise before publishing
Search the files for `YOUR_` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`

Review the education wording, experience dates/title, project descriptions and skills. Add repository links and screenshots only after confirming the projects are ready to be public.

## Publish
This is a static website and can be hosted on GitHub Pages, Netlify or another static hosting provider. Keep `index.html`, `styles.css` and `script.js` together in the published folder.
